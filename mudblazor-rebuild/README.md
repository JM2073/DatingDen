# Relationship Planner Rebuild

This is the separate Blazor/MudBlazor rebuild workspace for the relationship planner.

## What it is

- A clean Blazor Web App scaffold
- MudBlazor integrated for Material-style components
- A separate project from the working Node/SQLite app

## Run it

```bash
dotnet run
```

Or from the project directory:

```bash
dotnet watch
```

## Current scope

- MudBlazor app shell and responsive layout
- A rebuild landing page
- A rebuild plan page

## Next step

This project is where we can port the current planner features one by one:

- SQLite persistence
- Calendar and agenda
- Reminders
- Anniversary tracking
- Mobile-first planner UI
